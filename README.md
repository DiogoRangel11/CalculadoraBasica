# 🧮 Calculadora Básica em Python

Projeto simples de uma **calculadora em Python**, desenvolvida para praticar lógica de programação e operações matemáticas básicas.

---

## 🚀 Funcionalidades

- Soma
- Subtração
- Multiplicação
- Divisão
- Interface via terminal

---

## 🛠️ Tecnologias Utilizadas

- Python 3.13.9

---
## 📚 Objetivo do Projeto

Este projeto foi desenvolvido com fins educacionais, visando fortalecer:

- Lógica de programação

- Uso de funções

- Entrada e saída de dados

- Boas práticas iniciais em Python

- Versionamento com Git e GitHub
---
## ▶️ Como Executar o Projeto

1. Execute o arquivo principal:
```bash
python Calculadora.py

📌 Exemplo de Uso
Escolha a operação:
1 - Soma
2 - Subtração
3 - Multiplicação
4 - Divisão

Digite o primeiro número: 10
Digite o segundo número: 5
Resultado: 15
```
